为什么选 FRAMPP？/ Why FRAMPP?

延续 LAMPP / XAMPP 的产品形态，把 Web 开发三件套打包成自包含安装包 / The LAMPP/XAMPP tradition, bundled into self-contained installers.

⚡ 一键安装 / One-click

下载 → 运行 → 开始开发。自动初始化（随机密钥、MariaDB 数据目录）并启动全部服务 / Download, run, and start coding. Automatic init and service start.

📦 自包含 / Self-contained

无需 root / 管理员权限，不依赖系统包管理器，目录可整体移动 / No root/admin, no system package dependencies, relocatable directory.

🤖 内置 Agent / AI-ready

内置 MCP 服务器，为 AI Agent 提供数据库与运行时工具接入层 / Built-in MCP server as the tool layer for AI agents.

组件 / Components

默认通道 8.5：FrankenPHP 1.12.7（PHP 8.5.9）· MariaDB 12.3.2 · Redis 8.10.1 · Composer 2.10.2 · Adminer 6.0.1 / Default channel 8.5

字母 / Letter组件 / Component角色 / Role
FFrankenPHP应用服务器（内置 Caddy、自动 HTTPS、worker 模式）/ App server (embedded Caddy, auto HTTPS, workers)
RRedis分布式缓存 / 队列 / 会话 / Cache, queue, sessions
AAgentMCP 服务器：AI Agent 工具接入层 / MCP server: tool layer for AI agents
MMySQL / MariaDB关系数据库（默认发行 MariaDB）/ Relational database (MariaDB by default)
PPHP主要开发语言 / Primary language
PPython自动化 / AI 负载支撑（可选）/ Automation & AI workloads (optional)

快速开始 / Quick Start

安装后访问：默认站点 http://127.0.0.1:8080/ · 控制面板 http://127.0.0.1:8081/ / After install, visit the default site and control panel.

LINUX · .run
# 下载后 / after download
chmod +x frampp-setup-8.5-0.2.0-linux-x86_64.run
./frampp-setup-8.5-0.2.0-linux-x86_64.run

# 指定目录 / custom directory
./frampp-setup-8.5-0.2.0-linux-x86_64.run \
  --prefix /opt/frampp

# 管理 / manage
~/frampp/bin/frampp status
WINDOWS · .exe
# 双击安装，自动初始化并启动 / double-click to install
# 或从源码运行 / or run from source
powershell -ExecutionPolicy Bypass -File installer/scripts/download.ps1
powershell -ExecutionPolicy Bypass -File installer/scripts/init.ps1
php control-panel/bin/frampp start all
php control-panel/bin/frampp status

✓ 默认站点 / Default site: http://127.0.0.1:8080/    ✓ 控制面板 / Control panel: http://127.0.0.1:8081/    ✓ 目录可整体移动 / relocatable
